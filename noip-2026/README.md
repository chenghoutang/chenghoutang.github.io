# 2026 NOIP 澳门赛区专题

静态专题入口为 `index.html`，从网站主页顶部的临时宣传栏进入。可直接用浏览器打开，也可随现有静态网站部署。

截至 2026-11-27，档案覆盖 171 位选手、13 所学校。按专题规则：今年未参加 CSP 者视为已退役。公开记录对应 85 位现役、86 位已退役；濠江高三毕业旅行时间冲突的鄧善恒、区景昭、王瑞麟再从预测中移除，因此最终预测榜为 82 人。退役者保留历年档案。**当前来源是公开评级名单，可能遗漏未获评级者；这不是 NOIP 报名或资格名单。**

本次新增匹配 144 条 2025 年 CSP、NOIP、MOI、NOI、IOI 战绩。所有战绩显式记录年份，避免把去年成绩误读为今年。IOI 英文姓名通过澳门电脑学会中文代表队名单核对；NOI 使用实际竞赛分计算，同时展示含附加分的官方总分。去年资料只补充本季已有选手，不额外引入往届选手。

2026 年另外收录 NOI 澳门获奖成绩 2 条、IOI 澳门完整成绩 4 条。NOI 使用官方修订版名单，仅含获奖选手，不把未列名者计作零分；IOI 四人均经澳门电脑学会中文代表队公告核对。两年的 NOI 实际总分均按含笔试的 700 分折算，IOI 按 600 分折算。

## 更新与复核

- `node scripts/collect-noip-2026.mjs`：重新联网收集公开表格，写入 `research.json`。官方公开表格可能只列评级者或获奖者。
- `node scripts/collect-noip-history.mjs`：联网收集 2025 年五类赛事成绩，写入 `history.json`，其中包含未与本季名单匹配的往届原始记录。
- `node scripts/collect-noip-international-2026.mjs`：联网收集 2026 NOI、IOI 及中文身份核对资料，写入 `international-2026.json`。
- `node scripts/build-noip-2026.mjs`：合并同校姓名字形，生成本地 `data.js` 和原创 SVG 盾徽。脚本含学校别名与简繁字形映射；新增学校必须补充映射，避免静默误归类。
- `node scripts/check-noip-2026.mjs`：使用本机 Chrome 验证所有选手情报卡、学校筛选、搜索、年级、分页、键盘操作、手机排版、素材链接和 `file://` 访问，截图及检查结果写入 `review/`。

网站不需要构建工具、数据库或密钥。字体有本机回退；比赛资料、校徽、盾徽及预测计算都保存在本地，浏览时不请求比赛数据接口。

## 动画演示

`presentation/index.html` 是从专题页“动画演示”按钮进入的全屏演出。共 18 个步骤、9 个章节，自动模式约 80–90 秒，也支持上一步、下一步、章节跳转、自动过场暂停和音乐开关。音乐由 Web Audio 实时合成，不携带第三方音乐文件，须由用户点击“启动演算”后播放。

五位亮眼选手按当前预测前五名动态选取，并搭配 MyGO!!!!! 高松灯、千早爱音、要乐奈、长崎爽世、椎名立希的官方动画角色立绘。素材下载与尺寸校验由 `scripts/collect-noip-presentation-assets.mjs` 完成，原始页面及逐图 URL 保存在 `presentation/assets/manifest.json`，页面内持续显示 © BanG Dream! Project 与官方来源链接。

濠江高三毕业旅行与比赛时间冲突名单为鄧善恒、区景昭、王瑞麟；三人同时从主预测榜与动画最终榜移除，鄧正浩、黄锦霖不受影响。名单状态由 `data.js` 的 `noipStatus` 统一驱动。

运行 `node scripts/check-noip-presentation.mjs` 会逐幕验证固定权重排行榜、未参赛者不升分、五张角色图、85 人入场、三名行程冲突选手移除、82 人最终揭榜、自动/手动控制、粒子画布、手机布局与 `file://` 访问，并把截图写入 `presentation/review/`。

预测公式统一实现于 `prediction.js`，共九项固定权重：2026 CSP 25%、MOI 15%、NOI 10%、IOI 20%；2025 CSP 8%、NOIP 12%、MOI 4%、NOI 3%、IOI 3%。总和保持 100%。缺失项目贡献 0，不再按已有项目重新归一化，因此赛事结算不会使未参赛者凭空升分；参赛者只获得非负证据分。提高组优先，入门组与普及组单独折算。情报卡展示九项固定权重、折算分与贡献。

校徽使用培正、濠江、劳校、圣若瑟五校官网素材，原始链接保存在 `data.js` 的学校条目中；其余是原创战队盾徽。所有中英文战队名均独立于校名，每队在战队卡及选手情报卡展示一条中二标语，学校名称仍作为归属资料保留。战队名与标语为专题创作，不表示学校授权或官方战队。

## 下线临时入口

在根目录 `index.html` 删除 `noip-2026/banner.css` 的样式引用与 `.noip-banner` 链接即可撤下广告。专题可继续作为归档保留；不自动刷新或伪装为正式赛果。
