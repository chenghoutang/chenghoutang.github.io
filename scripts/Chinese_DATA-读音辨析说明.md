# 字音练习的逐项辨析

2026-11-20 为现有 1,682 条词语记录补充干扰读音解释，覆盖全部 **1,050 组“考查字＋错误读音”**。原题面、答案、干扰项和浏览器存储格式不变。

作答后，页面按 A–D 逐项展示本词中的正确读音。对读音配对错误的选项，再说明该字是否有题中所标的读音，以及适用的例词或用法。判断的是**这个汉字**是否有这个读音，不是问拼音是否能对应其他汉字。

## 类型

| 类型 | 显示方式 | 例子 |
| --- | --- | --- |
| 其他语境中的读音 | 列出本字采用该读音的词语 | “装载”误标 zǎi：有此音，例如“记载、刊载”；本词读 zài |
| 姓名、地名、书面语等特殊读音 | 说明适用范围，列例词 | “戛然而止”误标 gā：有此音，例如法国地名“戛纳”；本词读 jiá |
| 古音、通假等 | 明确标注古代用法，不当作现代本词的另一答案 | “挑剔”误标 tì：古字书有同“剃”的音义；现代本词读 tī |
| 地区异读 | 明确说明大陆普通话答题标准 | “沟壑”误标 huò：部分地区国语辞书收此音；本题采用 hè |
| 普通话常用读音中未收录 | 明确指出不能作为本词中该字的读音 | “氛围”的“氛”误标 fèn：大陆普通话采用 fēn |
| 扩展字书收音，例词未核实 | 显示收音情况与核对边界，不编造词义或例词 | 暧 nuǎn、亘 gèng、佝 jū、偬 cōng、蜷 juǎn、勖 mào、怏 yāng、汲 jī、蜒 dàn、涮 shuā，共 10 组 |

“选出正确配对”的题型有三个错误配对，三者分别解释；“选出错误配对”的题型有一个错误配对，也会解释其余三个正确选项。例词中仍突出显示对应考查字。

## 数据及依据

- `Chinese_DATA.json`：词语、考查字、正确读音、干扰读音。
- `Chinese_READINGS.json`：按“考查字＋干扰读音”保存分类、说明和例词，供页面使用。
- `scripts/pinyin-reading-evidence.json`：769 个考查字的汉典来源、访问时间、返回状态和字头拼音；并保留特殊读音的补充查阅来源。字头拼音不是全部古义、地区读法的穷尽清单。
- `scripts/pinyin-reading-overrides.mjs`：人工整理的特殊例词、古义与地区差异。例子不一定是常用现代词，页面会标注“例词或用法”。

常用其他读音优先采用已核对题库中的同字例词；缺少同字例词时，查阅汉典基本解释、详细解释及其古辞书栏目，并对部分条目补充查阅汉语国学。使用 [pinyin-data v0.15.0](https://github.com/mozillazg/pinyin-data/tree/v0.15.0) 辅助筛查扩展字音，**不将转拼音字库中存在某个音自动等同于该音有可用于现代题目的义项**。

无需联网即可构建和练习：

```sh
node scripts/build-pinyin-reading-notes.mjs
node scripts/build-pinyin.mjs
node scripts/check-pinyin.mjs
node scripts/check-pinyin-page.mjs
```

新增或调整干扰读音时必须同步补充说明；构建程序会拒绝遗漏的解释，并要求“有此读音”的记录附带例词或明确用法。需要重新查阅来源时，执行 `node scripts/review-pinyin-readings.mjs`，报告放在系统临时目录的 `dengduck-chinese-dictionary-review/character-readings.json`；人工复核后再更新仓库中的证据与说明，避免网络词典变化自动覆盖已审阅的内容。

校验包括全部干扰读音覆盖、JSON 与离线内嵌数据一致、逐项解释及 HTML 转义、10,000 道随机题、两种题型的页面显示、手机排版，以及作答统计和错题本刷新恢复。
