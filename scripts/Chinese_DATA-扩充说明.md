# 字音题库扩充

2026-11-20 新增 650 条，题库由 1,032 条增至 **1,682 条**，覆盖 **769 个考查字、1,561 个不同题面**。同一词语考查不同汉字时分别计为一条；一道选择题仍不重复出现同一词语。

全部题目已增加错误配对的读音辨析，说明该字是否有此读音，并列出例词或特殊用法，见 [逐项辨析说明](Chinese_DATA-读音辨析说明.md)。

新增内容包括 450 条易误读词与成语、200 条多音字及形近字辨音，例如：

| 词语 | 考查字 | 读音 |
| --- | --- | --- |
| 干涸 | 涸 | hé |
| 戛然而止 | 戛 | jiá |
| 恪守 | 恪 | kè |
| 锲而不舍 | 锲 | qiè |
| 记载／装载 | 载 | zǎi／zài |
| 屏息／屏障 | 屏 | bǐng／píng |
| 薄暮／薄饼 | 薄 | bó／báo |
| 提供／供认 | 供 | gōng／gòng |
| 朝霞／朝廷 | 朝 | zhāo／cháo |
| 仔肩／仔细／牛仔裤 | 仔 | zī／zǐ／zǎi |

新增条目使用中国大陆普通话读音。每条均对照汉典词条的完整拼音，并与 [phrase-pinyin-data 0.20.0](https://github.com/mozillazg/phrase-pinyin-data/tree/v0.20.0) 交叉匹配考查字的位置。完整词语拼音用于核对，正式题库的 `right` 仍只保存 `target` 指定的一个字的读音。

候选中“睢盱（考查睢）、骠悍、缲丝、泄露、频数”等存在来源冲突，未加入；“惝恍”有异读，未用另一个读法充当错误选项；“规矩、蹊跷”等有轻声或语体差异，相关候选也未加入。没有将查不到的整句或人名机械改成词典顶部的默认读音。

逐条词典 URL、访问时间、返回状态、完整词语拼音、考查字读音及交叉比对拼音存放在 [扩充数据与核对记录](pinyin-expansion-2026-11.json)。这是来源记录与语境筛选，不代表词典彼此独立或不存在异读；先前 1,032 条的校订依据仍见 [联网核查记录](Chinese_DATA-联网核查.md)。

原有 1,032 条记录保持不变。新增记录只追加到 `Chinese_DATA.json`；页面内嵌题库同步更新，直接打开 `pinyin.html` 也能练习。作答统计和错题本沿用现有存储，不重置。

维护命令（仓库根目录）：

```sh
node scripts/expand-pinyin.mjs
node scripts/build-pinyin.mjs
node scripts/check-pinyin.mjs
node scripts/check-pinyin-page.mjs
```

扩充脚本可重复执行；若已有同题面、同考查字但答案不同的记录，会报错而非覆盖。校验覆盖逐条来源记录、题库与内嵌数据一致、重复及冲突记录、10,000 道随机题，以及每条新增记录在两种题型中的使用。

`node scripts/review-pinyin-expansion.mjs` 可重新查询本批字词的汉典页面，原始响应与初筛报告存放在系统临时目录的 `dengduck-chinese-dictionary-review` 中。脚本会复用成功缓存；清除特定词的缓存后可重新抓取。初筛报告供复核，不直接覆盖正式题库。
