# 数学练习

2300 道自编单项选择题，30 个模块。原有简单、中等、困难各 600 题，每种题型含 10 道参数变式。新增地狱难度 500 题，包含 25 种综合题型，每种含 20 道参数变式。每题有四个选项、唯一答案和解析。

建议用时：简单 15 秒、中等 120 秒、困难 300 秒、地狱 600 秒。题型与用时用于分级练习，包含基础微积分拓展。新增 500 题分两批发布，第 7 批 300 题、第 8 批 200 题。

页面可从主页的“学习”文件夹进入，也可直接打开 `index.html`。KaTeX 和字体均保存在本地，数据通过普通脚本加载，支持 `file://` 离线打开。练习记录、错题与收藏保存在当前浏览器的 localStorage 中。

## 维护题库

题目源文件为 `../scripts/math/batch-1.mjs` 至 `batch-6.mjs`，每批五个模块、300 题；新增地狱题源文件为 `../scripts/math/hell.mjs`，由第 7、8 批构建。修改题目后重新构建对应批次：

```sh
node scripts/build-math-bank.mjs 1
node scripts/check-math-bank.mjs
node scripts/check-math-hell.mjs
node scripts/check-math-exam.mjs
node scripts/check-math-page.mjs
```

命令从仓库根目录运行。构建结果为 `data/batch-N.json` 与对应离线脚本，清单与练习/试卷页面的数据脚本由构建程序更新。题号 M0001–M2300 稳定对应题型与参数，请避免随意调整顺序，以免影响已有浏览器记录。

## 随机试卷

`exam.html` 从全库抽取 20 题：简单 4、中等 6、困难 8、地狱 2。题目不重复，并优先选择不同题型。每题 5 分、总分 100，建议总用时为 73 分钟；计时可暂停，超时不强制交卷。交卷前可修改选项，交卷后统一评分并展示解析，未答题计零分。替换未交卷试卷和交卷操作均在页面内确认。

当前试卷与作答独立保存在 localStorage 的 `dengduck-math-exam-v1` 中，刷新后恢复并暂停计时；不修改单题练习记录。浏览器不允许持久存储时，仍可在当前页面完成试卷。重新出卷会替换当前试卷，暂不保存历史试卷列表。

校验覆盖题量、题号、难度分布、选项、公式渲染、资源路径，并对参数边界、计数概率、几何关系、导数和积分进行数值或枚举检查。浏览器检查使用 Windows 上的 Chrome，验证离线与 HTTP 访问、主页入口、作答和保存、筛选、计时及手机长公式布局。
