# NetLab · HCIA 本地互动学习站

推荐：双击「启动学习站.cmd」，浏览器会打开本地网站。关闭服务窗口或按 Ctrl+C 可停止服务。

也可直接双击 index.html，无须安装依赖、无须联网。命令行启动方式：

    node server.mjs --open

默认地址 http://127.0.0.1:8765，端口被占用时自动尝试后续端口，以窗口提示为准。服务仅绑定本机 127.0.0.1。网站没有 CDN、外部字体、远程图片、账号服务或统计脚本。

## 内容范围

- HCIA.pdf 原文件共 961 页，本次按 PDF 阅读器的第 1–200 页（不是章内重置的印刷页码）制作。内容依次为网络基础、网络参考模型、VRP 基础、IPv4 与子网、IP 路由（至路由递归第二页）。
- 《2026–2027 高三 9 云计算与网络练习卷》2 页全部题目：10 选择、5 判断、2 简答、1 计算，共 100 分、60 分钟。云计算、虚拟化、DNS、DHCP、NAT 等相应补充另列一章。
- 逐页资料保留 200 页提取原文，关联课程，并可跳转本地原 PDF 图文。sources/HCIA-p1-200.pdf 为原文件前 200 页摘页，顺序不变；sources/practice.pdf 是完整原卷。
- 教材 © 2020 华为技术有限公司，原文归原权利人。课程是按上述资料编写的本地学习辅导。原卷未附答案，站内参考解析按网络原理编写，并非官方标准答案。

## 互动内容

12 个实验：数据封装、TCP 握手/序号/窗口/挥手、ARP、交换机与 Hub、拓扑故障、32 位子网计算器、路由匹配/优选/递归、TTL 探测、IPv4 分片、VRP 命令模拟、云服务与弹性、DNS/ARP/NAT 网页访问流程。每项实验有理解挑战，答对记录完成。

VRP 终端是限定指令集的教学模拟，不连接设备、不发送真实网络数据。输入 ? 查看支持指令，支持历史和唯一补全。拓扑实验展示图的物理连通性，实际网络的环路与冗余仍依赖相应协议。

原卷客观题自动评分 60 分，判断题说明由学习者对照解析自行核对；主观题提供逐项参考与自评，共 40 分，合计 100 分。计时在刷新后继续，时间到自动交卷；浏览器休眠或网站关闭期间经过的时间也计入，重新打开时按截止时间提交。提前交卷会按当前答案评分。

补充题库及随机子网练习支持即时解析。答错加入错题本，随后答对自动移除；重复作答计入累计次数。

## 进度与备份

完成课程需点击「标记完成」。记录保存在当前浏览器 localStorage，清浏览器数据会丢失。file:// 和 http:// 为不同来源，进度不互通，推荐固定用启动脚本打开。侧栏向下箭头可导出 JSON，在「逐页资料」底部导入以恢复；请定期备份。

## 勘误和边界

- HCIA PDF p141 表格将链路本地写成 169.254.0.0/24，正文为 /16；网站保留原文，按正确 /16 讲解。
- IPv4 IHL 字段以 4 字节计，5 对应 20 字节；/31、/32 不套普通子网减二规则。
- 静态路由高可用是非题按普通单路静态场景判 T，并解释跟踪和冗余配置的例外。
- 教材为 2020 年资料，其认证设置、VRP 产品现状和设备默认值按原资料语境讲解，实际操作应查对应版本文档。
- 提取原文不能完整呈现图形、版式、上下标，图文以本地 PDF 为准。

## 文件说明与检查

index.html / styles.css：页面与样式；content.js：课程；questions.js：题库与主观题细则；labs.js：实验；app.js：导航、记录与答题；data/source-data.js：离线原文。Python 提取脚本只用于制作资料，日常使用不需要 Python。
